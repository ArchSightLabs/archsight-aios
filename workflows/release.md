# Release 流程

状态：治理基线  
适用场景：版本发布、部署、交付验收、回滚准备

---

## 目标

确保交付内容可验证、可回滚、风险可控。

## 角色路由

```text
Mason -> Argus -> Hephaestus -> Mason
```

- Mason：确认发布范围、依赖和交付清单。
- Argus：审查质量、安全和风险。
- Hephaestus：执行构建、部署、脚本和发布动作。

## 输入

- 发布范围。
- 变更摘要。
- 测试结果。
- 回滚策略。
- 环境和权限说明。

## 输出

- 发布记录。
- 验证结果。
- 回滚路径。
- 已知风险。

## 执行步骤

1. 冻结发布范围。
2. 确认测试、lint、类型检查或必要人工验证已完成。
3. 确认配置、环境变量和权限。
4. 执行发布。
5. 做发布后验证。
6. 记录结果和风险。

## 验收标准

- 发布范围清晰。
- 关键验证通过。
- 回滚路径明确。
- 无未说明的高风险项。

## 禁止事项

- 不在验证缺失时发布。
- 不在回滚路径不清晰时发布高风险变更。
- 不把未完成事项包装成已完成。
