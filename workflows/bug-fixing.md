# Bug 修复流程

状态：治理基线  
适用场景：缺陷修复、回归修复、线上问题定位

---

## 目标

先复现和定位，再做最小修复，最后用回归验证证明问题已解决。

## 角色路由

```text
Argus -> Mason -> Hephaestus -> Argus
```

- Argus：确认缺陷、风险级别和回归范围。
- Mason：拆解修复任务并确定验证路径。
- Hephaestus：执行最小修复。
- Argus：复审修复是否引入新风险。

## 输入

- 错误现象。
- 复现步骤。
- 日志、截图、测试失败或用户反馈。
- 期望行为。

## 输出

- 根因说明。
- 最小修复。
- 回归测试或验证记录。
- 风险说明。

## 执行步骤

1. 复现问题或收集足够证据。
2. 定位根因，不用猜测替代证据。
3. 判断影响范围。
4. 优先补回归测试；无法测试时说明原因。
5. 执行最小修复。
6. 运行相关验证。
7. 复查 diff，确认没有无关改动。

## 验收标准

- 缺陷已复现或证据充分。
- 根因解释与代码改动对应。
- 修复覆盖原问题。
- 相关验证通过。
- 没有引入无关行为变化。
