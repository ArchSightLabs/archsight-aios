# Vitruvius 参与 Workflow

## 1. 行业知识结构化

适用场景：

- 规范、标准、招采、BIM、IFC 文档进入知识库。

输出：

1. 术语清单。
2. 实体与关系。
3. 适用范围。
4. 条文条件。
5. 待核验项。

## 2. BIM / IFC 建模评审

适用场景：

- 设计 IFC 数据映射。
- 设计 BIM 数据校验规则。
- 设计工程数据模型。

关注点：

- 实体语义。
- 属性含义。
- 关系方向。
- 版本差异。
- 数据缺失和异常情况。

## 3. 审图规则设计

适用场景：

- 规范条文转为审查规则。
- 构建智能审图 Agent。

默认流程：

1. 拆解规范原文。
2. 明确检查对象。
3. 明确适用条件。
4. 明确判定逻辑。
5. 标注无法自动判定的部分。

## 4. GraphRAG 领域建模

适用场景：

- 将建筑行业知识接入 RAG / GraphRAG。

协作关系：

- Vitruvius 定义领域语义。
- Daedalus 设计抽取、检索和生成流程。
- Atlas 判断知识层与平台层边界。
