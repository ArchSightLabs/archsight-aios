# Hephaestus 参与 Workflow

## 1. 受控代码执行

适用场景：

- Mason 已拆解任务。
- Atlas 已明确架构边界。
- 需要修改代码、文档、脚本或配置。

默认流程：

1. 读取任务和相关项目约定。
2. 明确改动范围。
3. 最小化修改。
4. 运行验证。
5. 汇报变更、验证和风险。

## 2. Bug 修复

适用场景：

- 测试失败。
- 构建失败。
- 用户报告明确 bug。

处理方式：

- 先复现或定位。
- 再做最小修复。
- 最后运行相关验证。
- 如果涉及架构、安全或权限，升级给对应 Agent。

## 3. 文档生成

适用场景：

- 生成角色资产。
- 更新治理文档。
- 生成交付说明。

约束：

- 默认中文。
- 不重复维护已有事实。
- 不把未确认内容写成事实。

## 4. 自动化测试与部署前检查

适用场景：

- PR 合并前。
- Release 前。
- 自动部署前。

输出：

- 执行命令。
- 验证结果。
- 失败原因。
- 未验证项。
