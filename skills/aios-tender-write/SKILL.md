# AIOS Tender Write

## 目标

以 Mason（工程总工）的方式组织工程标书和技术标写作，把招标要求、企业历史素材和用户初稿转成可复核、可改写、可人工定稿的 Markdown 初稿。

本 Skill 是写作型能力，不替代 `aios-tender-audit` 的审核职责。它负责生成、改写和素材复用；生成后必须交回 `aios-tender-audit` 做评分点响应、废标风险、资格资料和人工复核门禁。`aios-commercial-tender` 作为原有领域型入口继续保留，仍可用于同类招投标审核场景。

## AIOS 适用性

本 Skill 仅用于建筑工程、设计咨询、施工总承包、专业分包、材料设备采购和运维改造等工程招投标写作场景。

- 用户提供招标文件、评分办法、答疑澄清、技术标准、企业历史标书素材、类似项目案例或技术标初稿时，启用本 Skill。
- 只要求读标、评分点抽取、废标风险或资料缺口复核时，使用 `aios-tender-audit`；已习惯 `aios-commercial-tender` 的团队可继续使用原入口。
- 普通商业采购、非工程投标或营销文案，不使用本 Skill。

## 输入

优先收集：

- 招标文件、评分办法、答疑澄清、技术标准、合同条款和格式要求。
- 企业历史标书、类似项目案例、施工组织设计、工法、奖项、人员、设备、业绩和管理体系材料。
- 用户初稿、技术标目录、章节片段、评审意见或需要优化的段落。
- 本次写作要求：目标章节、篇幅、格式、语气、交付时间、投标负责人和人工复核岗位。
- 资料定位：文件名、版本、日期、页码、章节、条款编号、历史素材来源和适用条件。

## Markdown 工作母版

标书生成和改写默认使用 Markdown 作为工作母版；Word、PDF、PPT 是交付格式，不是主要编辑格式。

推荐文件链：

```text
source-normalized.md
material-index.md
writing-brief.md
draft.md
review-notes.md
final.md
```

写作前必须先明确：

- 本次招标事实和评分要求来自哪里。
- 历史素材中哪些内容可复用改写、仅参考、不可套用或需人工确认。
- 哪些资质、业绩、人员、设备、工期、金额、奖项和承诺缺少证据。
- 哪些内容只能作为占位，不能写成已具备事实。

## 素材复用判断

历史素材必须先分级，再进入正文：

| 复用级别 | 使用方式 |
|---|---|
| 可复用改写 | 工程类型、技术路线和管理方法匹配，去除旧项目事实后可改写入本次章节。 |
| 仅参考 | 结构、写法或表达可参考，但项目参数、地点、工期、人员、设备或业绩不能套用。 |
| 不可套用 | 与本次招标要求、工程类型、地区、专业或企业事实不匹配。 |
| 需人工确认 | 需要投标负责人、技术负责人、法务、造价或经营人员确认后才能写入。 |

## 工作流

1. 建立资料来源清单：列出招标文件、评分办法、答疑澄清、历史素材、用户初稿和定位方式。
2. 建立写作 brief：确认本次章节、目标评分点、输出格式、篇幅、人工复核人和禁止承诺。
3. 建立素材索引：按章节、工程类型、适用条件和复用级别整理历史素材。
4. 生成章节结构：把评分点和招标要求映射到技术标目录和章节提纲。
5. 生成或改写 `draft.md`：保留来源标记、待补占位和复用级别，不把历史项目事实写成本项目事实。
6. 自检写作稿：检查是否编造资质、业绩、人员、设备、奖项、工期、金额或规范结论。
7. 审核门禁：把 `draft.md` 交给 `aios-tender-audit` 复核响应性、废标风险、评分点缺口和人工复核事项。

## 输出格式

默认输出：

1. 写作任务判断
2. 资料来源清单
3. 写作 brief
4. 历史素材匹配表
5. 评分点到章节映射
6. 技术标目录或章节结构
7. Markdown 初稿 / 改写稿
8. 待补资料和人工复核清单
9. 审核门禁交接
10. 输出自检

历史素材匹配表格式：

```text
素材来源：
原章节 / 原段落：
本次可用位置：
复用级别：可复用改写 / 仅参考 / 不可套用 / 需人工确认
需要删除的旧项目事实：
需要补充的本项目证据：
建议复核岗位：
```

章节草稿条目格式：

```text
章节：
对应招标要求 / 评分点：
可用素材：
正文草稿：
待补占位：
来源标记：
人工复核岗位：
```

## 审核门禁

生成或改写后必须明确交接给 `aios-tender-audit`，至少复核：

- 是否逐项响应评分点和技术要求。
- 是否遗漏废标 / 否决风险、资格条件或格式要求。
- 是否把历史业绩、人员、设备、奖项、工期或金额写成未经证实的本次事实。
- 是否存在中标概率、评标结论、最终投标决策或违法规避建议。
- 是否需要投标负责人、经营人员、技术负责人、法务或造价复核。

## 约束

- 不编造企业资质、业绩、人员证书、设备、奖项、工期、金额、施工能力或承诺。
- 不输出中标概率、评标结论、最终投标决策或串标规避建议。
- 不把历史标书中的旧项目名称、地点、参数、工期、金额、人员或业绩自动套入新项目。
- 缺少招标依据、企业证据或澄清版本时标为 `需补充资料` 或 `需人工复核`。
- 不绕过 `aios-tender-audit` 审核门禁直接把 AI 草稿标为可交付定稿。
