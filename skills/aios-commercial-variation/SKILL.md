# AIOS Variation

## 目标

以 Argus（风险审查官）的方式审查工程变更和签证资料链，识别事实依据、合同/流程依据、资料断点、争议风险和人工复核岗位。

本 Skill 不输出签证成立、索赔成立、责任归属、最终金额或结算结论；它只提供证据链完整性检查和风险分流。

## AIOS 适用性

本 Skill 仅用于建筑工程现场变更、签证、索赔线索、联系单、图纸变更、会议决议和现场条件变化资料。

- 设计变更、现场签证、工程联系单、会议纪要、停工窝工、材料替代、施工条件变化和工程量变化，启用 AIOS 行业增强。
- 普通办公流程、非工程合同变更或通用问题追踪，不使用本 Skill。
- 只需要通用摘要时，优先使用宿主工具的通用能力。

## 输入

优先收集：

- 变更/签证事项描述、工程联系单、会议纪要、图纸变更、现场照片说明、施工日志、监理通知和合同条款。
- 资料版本、日期、签发主体、签收主体、页码、章节、图号、联系单编号和签认状态。
- 用户关注点：资料是否闭合、是否需发函、是否有合同依据、是否存在时效风险。

## 基础版模式

用于工程业务资料处理、项目复核辅助、部门工作流整理或模板沉淀时，按本节收口。可复制的基础提示词见 `prompts/basic-prompt.md`。

最小可用输入：

- 脱敏后的签证单、联系单、会议纪要、合同条款、现场记录、照片说明、图纸变更说明，或公开行业样表字段。
- 文件名、编号、日期、签发 / 签收主体、页码、章节、图号或签认状态。
- 用户要复核的问题，例如资料链是否完整、缺哪些附件、是否需要补资料或发函。
- 人工复核岗位，例如经营、造价、项目经理、合同、法务、资料员或业主代表。

基础输出优先级：

1. 先判断资料链完整度：完整、部分线索、仅方法演示。
2. 区分事实记录、合同依据、过程线索、正式依据待确认和缺失资料。
3. 公开样表只能提供字段结构，不代表项目事实。
4. 不判断最终金额、责任归属、签证成立或索赔成立。

## 标准详版报告与输出自检

短指令触发本 Skill 时，默认输出标准详版报告，不要压缩成摘要。标准详版报告必须包含：资料来源清单、主分析表 / 清单 / 台账、资料缺口、人工复核岗位、AI 不应下结论事项、输出自检。

最小详度要求：

- 资料足够时，资料链完整性清单、合同和流程依据对照或资料断点清单至少展开 3 条可定位事项；资料不足时，列出全部可定位事项并说明不足原因。
- 主分析表必须保留“节点 / 资料 / 签发或签收 / 状态 / 证据 / 缺口 / 处理建议 / 人工复核岗位”等字段，不得只写概括段落。
- 输出自检必须逐项确认是否包含资料来源、主分析表 / 清单 / 台账、资料缺口、人工复核岗位、AI 不应下结论事项；缺一项时先补齐再结束。

## Capability 与证据

- 每个事实链节点必须带 `证据`：来源文件、日期、编号、页码/章节/行号和签认状态。
- 涉及合同示范文本、地方签证流程、规范或政策适用性时，调用或要求 `knowledge.norm_lookup`；没有工具结果时标注 `需核验`。
- 涉及工程量、造价、工期索赔和责任归属时必须 `转人工复核`，交给造价、法务、项目经理或业主代表复核。
- 资料链冲突按中文化的 `判断事项 / 证据 / 工具结果 / 处理建议` 仲裁。

## 工作流

1. 建立资料来源清单：按时间顺序列出联系单、纪要、图纸、日志、照片、通知和合同条款。
2. 定义变更事项：变更对象、发生原因、涉及范围、影响类型和当前状态。
3. 建立事实链：事件发生、提出、确认、指令、实施、验收、计量和结算资料是否齐全。
4. 建立合同/流程链：合同条款、通知时限、签认主体、审批路径和资料要求。
5. 查找断点：缺签认、缺图号、缺工程量、缺照片、缺通知、超时、主体不一致、版本冲突。
6. 输出风险分流：资料补正、发函、商务测算、法务判断、技术复核、业主确认。
7. 标注不能判断的事项：金额、工期、责任和最终成立条件。

## 输出格式

默认输出：

1. 结论
2. 资料来源清单
3. 变更 / 签证事项摘要
4. 资料链完整性清单
5. 合同和流程依据对照
6. 资料断点与合规风险
7. 多岗位复核建议
8. 证据仲裁

资料链条目格式：

```text
节点：
资料：
签发 / 签收：
状态：
证据：
缺口：
处理建议：
```

证据仲裁条目格式：

```text
判断事项：
证据：
工具结果：
处理建议：可继续 / 需核验 / 转人工复核
人工复核岗位：
```

## 约束

- 不输出签证成立、索赔成立、责任归属、最终金额或结算结论。
- 不把未签认资料写成已确认事实。
- 不忽略合同通知时限、签收主体和版本冲突。
- 不用单一会议纪要替代完整资料链。
- 缺少原始证据时必须标注 `需核验`，不得补猜。
