# AIOS Tender

## 目标

以 Mason（工程总工）的方式组织工程招投标资料解析，把招标文件转化为可执行的响应矩阵、废标风险清单、资格资料清单和技术标准备路径。

本 Skill 不替代投标负责人、法务、商务、造价或招标代理复核；不输出中标概率、围标串标判断或最终投标决策。

## AIOS 适用性

本 Skill 仅用于建筑工程、设计咨询、施工总承包、专业分包、材料设备采购和运维改造等工程招投标场景。

- 招标公告、招标文件、评分办法、技术标准、答疑澄清和投标文件目录，启用 AIOS 行业增强。
- 普通商业采购、招聘、行政采购或非工程投标，不使用本 Skill。
- 只需要普通文件摘要时，优先使用宿主工具通用能力。

## 输入

优先收集：

- 招标文件、评分办法、资格预审文件、答疑澄清、图纸清单、技术标准和合同条款。
- 文件版本、发出日期、页码、章节、条款编号和附件编号。
- 企业已有资料：资质、业绩、人员证书、设备、财务、信用、类似项目案例。
- 用户关注点：废标项、评分点、技术标目录、资料缺口、响应难点。

## 基础版模式

用于工程业务资料处理、项目复核辅助、部门工作流整理或模板沉淀时，按本节收口。可复制的基础提示词见 `prompts/basic-prompt.md`。

最小可用输入：

- 脱敏招标文件片段、评分办法、技术标要求，或 AI 标书工具试用后的人工检查问题清单。
- 文件名、版本、日期、章节 / 页码 / 条款标题。
- 用户要复核的问题，例如评分点响应、废标风险、资料缺口或技术标目录。
- 人工复核岗位，例如投标负责人、经营人员、技术负责人、法务或造价。

基础输出优先级：

1. 先判断输入类型：真实招标文件 / 评分办法、AI 生成技术标后的人工检查问题清单、工具咨询或混合资料。
2. 若缺少真实招标原文，明确写出“缺少可验证招标依据”，只输出问题回应矩阵和响应矩阵模板，不输出真实读标结论。
3. 输出 AI 技术标复核问题回应矩阵、评分点响应矩阵、资料缺口和人工复核事项。
4. 废标、资格条件和评分分值缺证据时标为 `需核验`，不得补猜。

## 标准详版报告与输出自检

短指令触发本 Skill 时，默认输出标准详版报告，不要压缩成摘要。标准详版报告必须包含：资料来源清单、主分析表 / 清单 / 台账、资料缺口、人工复核岗位、AI 不应下结论事项、输出自检。

最小详度要求：

- 资料足够时，废标 / 否决风险清单、资格条件清单或评分点响应矩阵至少展开 3 条可定位事项；资料不足时，列出全部可定位事项并说明不足原因。
- 主分析表必须保留“事项 / 要求 / 证据 / 缺口 / 处理建议 / 人工复核岗位”等字段，不得只写概括段落。
- 输出自检必须逐项确认是否包含资料来源、主分析表 / 清单 / 台账、资料缺口、人工复核岗位、AI 不应下结论事项；缺一项时先补齐再结束。

## Capability 与证据

- 每个废标风险、评分点和资格条件必须带原文定位。
- 涉及法规、地方交易规则、规范标准或政策适用性时，调用或要求 `knowledge.norm_lookup`；没有工具结果时标注 `需核验`。
- 评分预测只能基于明确评分办法和已提供资料；缺资料不得脑补。
- 冲突、澄清版本不一致或关键证据缺失时输出 `处理建议：转人工复核`。

## 工作流

1. 建立资料来源清单：列出招标资料、答疑澄清、版本和定位方式。
2. 抽取项目基本事实：招标范围、工期、质量目标、资质要求、投标截止、保证金和评标办法。
3. 标出废标/否决项：原文条件、触发风险、所需证明材料和责任人。
4. 抽取资格条件：资质、业绩、人员、证书、财务、信用、联合体和设备要求。
5. 建立评分点响应矩阵：评分项、分值、响应材料、企业已有证据、缺口、负责人。
6. 生成技术标目录建议：只基于招标文件要求和工程类型，不额外扩展无关章节。
7. 标注澄清和人工复核事项：法务、商务、技术、造价、投标负责人。

## 输出格式

默认输出：

1. 结论
2. 资料来源清单
3. 项目和资料概览
4. 废标 / 否决风险清单
5. 资格条件和证明材料清单
6. 评分点响应矩阵
7. 技术标目录建议
8. 人工复核与澄清问题
9. 证据仲裁

响应矩阵条目格式：

```text
评分项：
分值：
响应材料：
已有证据：
缺口：
证据：
处理建议：
```

证据仲裁条目格式：

```text
判断事项：
证据：
工具结果：
处理建议：可继续 / 需核验 / 转人工复核
```

## 约束

- 不输出中标概率、最终投标决策或违法合规结论。
- 不把未提供的企业资质、业绩或证书当作已具备。
- 不忽略答疑澄清版本；版本冲突必须标注。
- 不替代投标负责人、法务、商务、造价或技术负责人审核。
- 对废标项使用保守口径：缺证据时标 `需核验`，不直接判定废标。
