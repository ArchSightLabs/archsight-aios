# AIOS Roadmap

## Phase 1：治理骨架

- 核心 Agent 角色资产。
- `archsight-*` Skills。
- Workflow、Runtime routing、项目模板。
- CLI 安装和 doctor。

## Phase 2：产品化闭环

- 统一 AIOS 命名和发布入口。
- 行为级测试。
- 治理、交付、记忆、知识工程政策。
- Hermes dry-run 同步与漂移检测。

## Phase 3：行业知识工程

- BIM / IFC / 规范知识源登记。
- RAG / GraphRAG 评估集。
- 审图规则图谱。
- 第二阶段 Agent 深化。

## Phase 4：企业级运行

- 真实 Hermes / 飞书集成。
- 权限审计。
- 多项目接入仪表盘。
- 发布和回滚自动化。
