# v1.5.0 Release Readiness

本清单用于 v1.5.0 正式发布前收口。v1.5.0 的版本主线是 **Knowledge Pack + 本地 Reference Runtime**。

## 发布硬门槛

- [x] `templates/knowledge-pack/` 提供空白 Knowledge Pack 工作台。
- [x] `templates/knowledge-pack-samples/scheme-review/` 提供端到端合成样板。
- [x] `archsight-aios knowledge:init` 可创建知识包工作台，且不覆盖已有文件。
- [x] `archsight-aios knowledge:validate` 校验文件链、对象模型、引用关系、lookup 规则和 eval 问题。
- [x] `archsight-aios knowledge:compile` 生成 `archsight-aios.knowledge-pack` 编译产物。
- [x] `archsight-aios knowledge:inspect` 输出知识包摘要。
- [x] `archsight-aios knowledge:lookup` 可查询编译产物并返回可追溯引用。
- [x] `archsight-aios knowledge:eval` 覆盖 found / not_found / conflict / inapplicable / need_context。
- [x] `knowledge.norm_lookup` 已通过本地 stdio MCP Reference Runtime 接入 Capability 仲裁。
- [x] `engineering-knowledge-pack-scorecard.json` 固定知识包质量维度。
- [x] `aios-tender` / `aios-tender-audit` / `aios-scheme` / `aios-scheme-audit` 作为短名任务型入口登记到 manifest，旧领域型入口继续保留。
- [x] `aios-contract-audit` / `aios-contract-draft`、`aios-daily` / `aios-daily-write`、`aios-meeting` / `aios-meeting-write` 扩充为正式技能包，合同草拟、日报生成和会议纪要生成均保留审核门禁。
- [x] `docs/industry-user-trial-guide.md` 提供建筑行业自助试用、资料脱敏、样例任务和人工复核边界说明。

## 版本同步点

正式 bump 到 `1.5.0` 时必须同步：

- `package.json`
- `gemini-extension.json`
- `.claude-plugin/plugin.json`
- `runtime/archsight-aios.manifest.json`
- `bin/archsight-aios.mjs` 中 MCP `clientInfo.version`
- `CHANGELOG.md`
- `RELEASE_NOTES.md`

## 当前边界

- 不包含生产级规范数据库。
- 不包含企业飞书 / Hermes / 多项目权限审计 Adapter。
- 不承诺自动合规、自动审图或正式签审结论。
- 合成样板只验证 Knowledge Pack 结构、查询、评估和 Capability 契约。
