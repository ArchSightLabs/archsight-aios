## 版本同步点

正式 bump 到 `1.4.0` 时必须同步：

- `package.json`
- `gemini-extension.json`
- `.claude-plugin/plugin.json`
- `runtime/archsight-aios.manifest.json`
- `bin/archsight-aios.mjs` 中 MCP `clientInfo.version`
- `CHANGELOG.md`
- `RELEASE_NOTES.md`

## 发布步骤

1. 冻结发布范围。
2. 更新版本同步点。
3. 跑完整发布级验证命令。
4. 提交 release metadata。
5. 创建 `v1.4.0` tag。
6. 推送 commit 和 tag。
7. 检查同名 GitHub Release 是否已存在。
8. 从 `RELEASE_NOTES.md` 提取 `## 1.4.0` 小节创建 GitHub Release。

## 当前阻断

截至本清单更新时，Codex / WorkBuddy 写作型 Skill 的 raw output 已归档并通过 scorecard 复核。正式发布前剩余工作是版本号同步、最终发布 commit 的完整验证、`v1.4.0` tag、push 和 GitHub Release。
