# Release Checklist

## 发布前

- [ ] 发布范围已冻结。
- [ ] 变更摘要已写清。
- [ ] `npm test` 或项目等价测试已通过。
- [ ] `doctor` / `smoke` 等治理检查已通过。
- [ ] Review 无 P0 / P1。
- [ ] 回滚路径已确认。

## 发布中

- [ ] 使用受控命令执行发布。
- [ ] 不手工修改未记录配置。
- [ ] 记录版本号、commit、操作者和时间。

## 发布后

- [ ] 执行冒烟验证。
- [ ] 记录已知风险。
- [ ] 如失败，按 `rollback-policy.md` 回退。
