# v1.4.0-writing-host-validation

## 结论

当前不能把 v1.4.0 标记为真实宿主验证通过。

本轮已经建立 `skill-runtime` 证据归档结构，并记录 Codex / WorkBuddy 的实际运行面阻断：

- Codex：本机能发现 WindowsApps `codex.exe`，但从当前 PowerShell 工作目录执行 `codex --help` 时被 Windows 拒绝访问。`npm run install:user` 已把写作 Skill 同步到 Codex skills 目录，但这只是安装证据。
- WorkBuddy：当前 shell 未发现 `workbuddy` 命令。`npm run install:user` 已把写作 Skill 同步到 WorkBuddy skills 目录，但这不是真实运行时触发证据。

## 归档规则

只有满足以下条件，才允许把 case 标为 `skillRuntimeConfirmed=yes`：

1. 宿主工具实际加载并触发对应 `$aios-*` Skill。
2. 原始输出全文已归档。
3. 输出中能看到对应写作 Skill 和审核门禁 Skill。
4. 输出不是把 `SKILL.md` 或 `basic-prompt.md` 当普通 prompt 粘贴运行。
