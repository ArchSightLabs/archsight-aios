# Prompt Registry

## 目标

Prompt 必须作为可评估资产维护，而不是散落文本。

## 登记字段

```text
名称：
版本：
适用场景：
输入：
输出：
禁止场景：
评估集：
最近验证：
负责人：
```

## 维护规则

Prompt 修改必须记录原因、预期行为变化和评估结果。
